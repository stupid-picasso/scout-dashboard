Read-only survey. Line numbers are from the tree at HEAD d697877. Git history is squashed (269 commits): `sw.js` changes in 93 of them, always with the 4 generated bundles; `pokemon-mechanics.js` in 16, always with the bundles and `sw.js`. Nothing else co-changes with the rules or Worker (1 commit each).
